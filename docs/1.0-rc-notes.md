# FitPlan 1.0 RC Notes

## Candidate Scope

FitPlan 1.0 RC focuses on an offline-first fitness planning loop:

- Create, edit, duplicate, delete, and activate local workout plans.
- Start a workout, track completed exercises, recover drafts, and save history snapshots.
- Review history by all, this week, and this month.
- Export and import local backup JSON without overwriting existing data.
- Optionally configure DeepSeek to generate a workout plan, preview it, edit it, and save it as a new plan.

## Stage 9 Readiness Goals

- Triage internal beta feedback in `docs/beta-feedback-log.md`.
- Fix P0/P1 issues before handing out a 1.0 RC APK.
- Preserve offline-first behavior when network or DeepSeek is unavailable.
- Keep Room schema unchanged during Stage 9 to avoid late migration risk.
- Produce debug and release APK build evidence in `docs/release-checklist.md`.

## Known Limits

- No login, cloud sync, sharing, or multi-device merge.
- API Key uses local DataStore storage, not encrypted storage.
- Release signing credentials are private local files and are not committed.
- History filters use simple local date ranges.
- AI plan quality depends on the configured model, API Key, and network.

## Rollback Guidance

- If an RC build has a P0/P1 issue, use the previous Stage 8 APK for internal testers.
- Do not migrate database schema during rollback.
- If backup import causes confusion, ask testers to export current data before trying another import.
- Keep beta feedback entries open until the fix is verified on a real device.
